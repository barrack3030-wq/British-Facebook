# British Facebook — Product Image CMS

CMS untuk membuat banyak variasi gambar produk British Propolis tanpa API AI.

## Fitur awal
- Upload banyak foto produk
- 5 template gambar
- Badge COD, Gratis Ongkir, Best Seller, Promo, Stok Terbatas
- Output 800, 1080, atau 1200 px
- Batch generation
- Download seluruh hasil sebagai ZIP
- Pemrosesan di browser, tanpa API AI

## Deploy
Repository ini dapat dipakai sebagai static site di GitHub Pages atau Vercel.

## Catatan
Versi awal menggunakan Canvas browser untuk compositing. Opsi penggantian background otomatis yang lebih canggih dapat ditambahkan pada tahap berikutnya tanpa AI API eksternal.
